## Метрики и где конкретно жирно

### 1. Bundle — **1482 KB** (сырой JS)

```
dist/assets/index-BBU89qgv.js  1,482 KB  (gzip: 350 KB)
```

**Проблема:** Весь Phaser (~1.4 MB) + игровой код запакован в один монолитный чанк. Phaser грузится вместе с TypeScript-исходниками, а браузер не может распараллелить загрузку.

**Фикс:** В [vite.config.ts](file:///c:/Workspace/WEB-Game/WEB-Game/vite.config.ts) добавить `manualChunks`:

```ts
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        phaser: ['phaser'],
      },
    },
  },
},
```

Итог: Phaser в отдельный чанк → браузер кеширует его между версиями, пересобираешь только `game.js`.

### 2. FCP — **984 мс**

Google порог «хорошо» = < 1800 мс, но это headless без сети. Реальная причина блокировки — **два `<link rel="stylesheet">` на Google Fonts** загружают шрифты до отрисовки страницы.

**Фикс:** Добавить `media="print" onload="this.media='all'"` или просто поставить `display=swap` (уже стоит). Либо вообще выкинуть Google Fonts и прописать системный стек:

```css
font-family: "Orbitron", "Segoe UI", system-ui, sans-serif;
```

— страница рендерится мгновенно, шрифт догружается асинхронно.

### 3. GC-давление от VFX — **26+ объектов на каждое попадание**

В [VfxSystem.ts](file:///c:/Workspace/WEB-Game/WEB-Game/src/game/systems/VfxSystem.ts):

- `createHitSparks` → 10 `Arc` + 10 `Tween` = **20 объектов**
- `createExplosion` → 24 частицы + 2 кольца = **26 объектов**

Все создаются через `this.scene.add.circle(...)` и уничтожаются в `onComplete`. При интенсивном бою (лазер 200 мс кд × 3 врага = 15 выстрелов/с) это **≈300 new/destroy на секунду** → регулярные GC-паузы.

**Фикс:** Заменить на [Phaser Particle Manager](https://newdocs.phaser.io/docs/3.87.0/Phaser.GameObjects.Particles.ParticleEmitter):

```ts
// Один раз в BootScene или ArenaScene
this.add.particles(0, 0, 'star', {
  lifespan: 300,
  speed: { min: 40, max: 160 },
  alpha: { start: 0.9, end: 0 },
  ...
});
```

Объекты берутся из пула — без GC.

### 4. HUD — `graphics.clear()` + полная перерисовка **каждый кадр**

В [Hud.ts](file:///c:/Workspace/WEB-Game/WEB-Game/src/game/systems/Hud.ts) метод `sync()` вызывается из `ArenaScene.update()` и заново рисует все 6 шкал, радар и слоты оружия через `fillRect/strokeRect` — **60 раз в секунду**.

**Фикс:** Dirty-флаги. Перерисовывать только те элементы, у которых значение изменилось. Радар — максимум 15 fps достаточно:

```ts
private lastHull = -1;
// В sync():
if (Math.round(player.hull) !== this.lastHull) {

}
```
